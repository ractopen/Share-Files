A simple repository for sharing and distributing files and application builds.

## 📦 Contents

- **Builds:** Various APKs and application binaries.
- **Documents:** Project-related files.

## 🚀 Usage

You can download the files directly from the repository or use the following command:

```bash
git clone https://github.com/ractopen/Share-Files.git
```
